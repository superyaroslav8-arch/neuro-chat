# Нейро-чат

**Полностью бесплатный AI-чат-помощник** с интерфейсом как у ChatGPT + расширенные функции.

## Возможности

- 💬 Чат с AI (как ChatGPT)
- 🖼 Создание фото по описанию
- 🎬 Создание видео до **25 минут** (длительность указываете сами)
- 🎵 Создание музыки по описанию
- 🖨 Генерация 3D-моделей для печати на 3D-принтере
- 🔐 Простая регистрация/вход (только логин + пароль, без лишних проверок)
- 🌙 Тёмный стиль интерфейса
- 📱 Адаптивный дизайн

Просто откройте `index.html` в браузере. Всё работает локально, данные хранятся в localStorage.
