# Нейро-чат

**Реальный проект** с настоящей генерацией фото.

## Реальная генерация фото
Используется **Pollinations.ai** (модель Flux) — без ключа, прямо в браузере:
`https://image.pollinations.ai/prompt/ВАШЕ_ОПИСАНИЕ?width=1024&height=1024&model=flux&nologo=true`

## Видео
Короткие клипы через Puter.js (Kling). Длинные (до 25 мин) требуют API-ключа (можно добавить).

## Как запустить
Откройте `index.html`.
