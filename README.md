# Нейро-чат

**Полностью бесплатный** AI-чат-помощник в стиле ChatGPT.

## Возможности

- 💬 Чат с переключением моделей: **Нейро-чат, Алиса, Grok, ChatGPT, Дед, Eve, Маруся, Claude, Gemini**
- 🌓 Светлая / тёмная тема (по умолчанию светлая)
- 🎨 Смена акцентного цвета (зелёный, синий, жёлтый, оранжевый, фиолетовый, розовый, красный, бирюзовый)
- 🔊 Включение / выключение звуков
- 📎 Прикрепление фото, видео и файлов
- 🎤 Запись голосовых сообщений
- 🖼 Создание фото · 🎬 Видео до 25 мин · 🎵 Музыка · 🖨 3D-модели
- 🔌 Коннекторы: GitHub, Gmail, Drive, Calendar, Slack, Notion, Spotify, YouTube
- 🔐 Регистрация / вход только по логину + паролю (логины уникальные, без лишних проверок)
- 📱 Адаптивный дизайн
